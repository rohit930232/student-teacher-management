# Student Teacher Management System

A web-based Student Teacher Management System developed using Java, JSP, Servlet, JDBC, HTML, CSS, JS, and SQL.

## Features

### Admin Module
- Manage students
- Manage teachers
- Manage staff
- Manage attendance
- Manage timetable
- Manage exams and results
- Send notifications and notices
- Manage online classes
- Dashboard analytics

### Teacher Module
- Upload assignments and notes
- Manage student attendance
- Create exams and results
- Conduct online classes
- View timetable
- Manage profile and settings

### Student Module
- View assignments and notes
- Check attendance
- View results and timetable
- Access online classes
- Receive notifications and notices
- Manage profile and settings

## Technologies Used

- Java
- JSP & Servlet
- JDBC
- SQL
- HTML
- CSS
- JavaScript
- Apache Tomcat

## Project Structure

- Controller Layer
- DAO Layer
- JSP Views
- CSS Styling
- Database Connectivity

## How to Run

1. Clone the repository
2. Import project into Eclipse
3. Configure Apache Tomcat server
4. Setup SQL database
5. Run the project on server
